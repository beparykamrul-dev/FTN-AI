# FTN AI Project Builder

FTN's internal AI can assist authorized FTN teams in building and maintaining FTN projects and services.

Capabilities:
- service/project specification
- architecture and dependency mapping
- module/task planning
- repository-aware developer notes
- test and release planning
- operational readiness summaries
- documentation and handoff generation

The FTN project builder is separate from customer AI context and follows repository IAM and approval boundaries.
