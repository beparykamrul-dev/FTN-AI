# FTN AI Service Experience

FTN AI should make the underlying FTN Cloud services understandable and useful to both individual customers and organizations. The experience layer is not only visual polish; it converts service health, usage, billing, support, and recommendations into clear outcomes.

## Customer experience

- Simple first response: what happened, what matters, and what to do next.
- Separate concise summary and expandable detailed evidence.
- Service-specific assistants with consistent FTN branding.
- Explain plans, limits, usage, billing, and service health in plain language.
- Proactive but non-intrusive recommendations.
- Accessibility and responsive mobile/web interaction.

## Organization experience

Organizations receive a workspace-oriented experience:

- service portfolio overview
- role-aware dashboards
- SLA/health summaries
- usage and cost summaries
- incident and support summaries
- compliance/audit visibility
- API/developer integration guidance
- executive summary with drill-down details

## Trust principles

The AI must not manufacture metrics, testimonials, uptime, savings, certifications, customer counts, or institutional claims. Evidence-backed information is preferred. Recommendations are clearly separated from facts.

## Service presentation

Each FTN Cloud service has a consistent presentation contract:

```text
Service
  -> Value
  -> Current status
  -> Usage / entitlement
  -> AI assistance
  -> Important summary
  -> Detailed evidence
  -> Action / request
```

This contract is shared across FTN Mail, DNS, storage, AI, billing, SMS, network, applications, and future cloud services.
