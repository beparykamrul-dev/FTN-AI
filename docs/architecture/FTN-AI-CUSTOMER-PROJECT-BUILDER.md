# FTN AI Customer Project Builder

Customer AI can help an authorized customer turn a requirement into a structured project plan and implementation workspace.

Capabilities:
- requirement capture and clarification
- project scope and milestones
- architecture suggestions
- task breakdown
- documentation generation
- test-plan preparation
- deployment checklist
- progress and risk summary

The builder prepares work and recommendations; repository, billing, deployment, or production side effects remain permission-controlled.
