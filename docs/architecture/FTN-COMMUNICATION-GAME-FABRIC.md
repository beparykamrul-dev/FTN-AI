# FTN Communication & Game Fabric

Realtime services are separated from core control traffic.

Communication supports authenticated chat, audio/video, group sessions and realtime signaling through replaceable adapters. TURN/STUN/SFU components are edge/POP aware.

Game services use regional/POP placement, matchmaking, session affinity, latency-aware routing, health checks and telemetry. Critical control functions remain isolated from game/media workloads.
