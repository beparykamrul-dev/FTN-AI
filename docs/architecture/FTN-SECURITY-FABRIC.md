# FTN Security Fabric

Security is an independent plane covering network, service, endpoint and data boundaries.

`Identity -> mTLS -> Authorization -> Segmentation -> Telemetry -> Detection -> Policy/Approval -> Mitigation -> Verification -> Audit`

Adapters may integrate Zeek, FastNetMon, eBPF/XDP, SIEM and threat-intelligence sources. The platform does not perform unauthorized surveillance or autonomous destructive actions.
