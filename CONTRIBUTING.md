# Contributing to FTN-AI

Thank you for your interest in contributing to **FTN-AI**! We welcome contributions from the community to make this project better.

## How Can I Contribute?

### 1. Reporting Bugs
If you find a bug, please create an issue on GitHub and include:
* A clear description of the problem.
* Steps to reproduce the issue.
* Expected vs. actual behavior.

### 2. Suggesting Enhancements
Have an idea for a new feature? Open an issue to discuss your proposal before starting development.

### 3. Pull Requests (PRs)
1. **Fork** the repository and create your branch from `main`.
2. Ensure your code follows the project's coding standards and production requirements (no demos, simulations, or prototypes).
3. Test your changes thoroughly.
4. Open a Pull Request with a clear description of what was fixed or added.

## Development Guidelines
* All code and project builds must be production-ready.
* Keep your commit messages clear, descriptive, and concise.

Thank you for helping improve FTN-AI!
