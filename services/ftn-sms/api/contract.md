# FTN SMS API V1

## Send

`POST /v1/sms/messages`

Required logical inputs:

- `sender_id`
- `recipient`
- `body`
- optional `scheduled_at`
- optional `priority`

The authenticated identity is derived from the session/token context; clients cannot impersonate another identity.

## Authorization

1. Authenticate request.
2. Resolve Account/IAM identity.
3. Check `sms.send` permission.
4. Validate Sender ID is approved and active.
5. Apply policy and rate limits.
6. Queue the message.

Privileged resend/cancel operations require the corresponding permission and audit event.

## Approval

Messages generated by AI follow the FTN approval policy. A pending approval is not submitted to the transport queue until approved.

## Response

Successful enqueue returns a server-generated message identifier and queue state. The API does not expose transport credentials or internal gateway details.

## Rate limiting

Limits are enforced server-side per identity, sender, recipient, and configured tenant policy. These identifiers are not emitted as Prometheus labels.

## Privacy

Request logging must redact message bodies and sensitive recipient data. SMS content is processed only by FTN-controlled services and configured operator transport paths.
