# FTN Visual Identity

## Primary Mark

FTN Signature Orbital Emblem is the primary visual identity for the FTN platform.

## Brand Mark

- Name: FTN
- Mark: custom FTN monogram
- Style: signature orbital emblem
- Core palette: deep navy, electric blue, controlled green, silver
- Primary usage: web, mobile apps, router firmware, FTN-WAN, servers, NOC, maps, certificates, documents and favicon

## Production Rule

The 3D/glossy artwork is a visual reference. Production assets should include a clean flat/vector master of the same mark for reliable rendering at small sizes, print, monochrome use and technical interfaces.

## Exclusions

The primary mark contains no service names, slogan, company expansion text or unrelated icons.
