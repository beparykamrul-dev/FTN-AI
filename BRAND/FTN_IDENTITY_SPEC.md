# FTN Identity Specification

## Primary mark
FTN Signature Orbital Emblem

## Production master
The primary production asset should be a clean vector/flat version of the approved FTN emblem. 3D/glossy renders are presentation variants only.

## Core visual language
- FTN monogram only
- Orbital/infinity-inspired geometry
- Deep navy foundation
- Controlled blue/cyan connectivity accent
- Green directional/growth accent
- No service names
- No slogan inside the primary mark
- No unnecessary decorative symbols

## Usage
The same master identity should be adapted consistently for web, Android, router firmware, FTN-WAN, NOC, servers, maps, documentation, certificates and favicon/app icons.

## Brand principle
"সেবাই কর্ম, সেবাই শান্তি" remains FTN's guiding principle, but is not part of the primary logo artwork.
